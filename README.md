A complete spot the difference game: two near-identical hand-drawn scenes side by
side, five levels of rising difficulty, timer, hints, combos, stars and
synthesised sound — all in plain static files, no network, no build step.

Play: open `game/index.html` in a desktop browser (or `node serve.ts` and visit
http://localhost:8080), then click the differences. Find them all before time
runs out.

Built for the [make.fun](https://make.fun/bounty/best-spot-the-difference-game-20261121-0451) "Make the best spot the
difference game" bounty.
